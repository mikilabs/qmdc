# Note [[note]]

- emphasis: guard __main__, name _x_, tag <b>bold</b>, star *y*, tick `z`
- strike: strike ~s~ and ~~d~~
- escaped: escaped \_e\_ and \*f\*
- entity: entity &amp; here
- autolink: autolink <https://a.example>
- titled: titled [t](https://b.example "T")
- image: image ![i](c.png)
- selfclose: break x<br>y
- nested: nested **bold with `code` and _em_**
- pair: backslash pair \\ then text
- literal: literal a\_b and \\_c\\_
